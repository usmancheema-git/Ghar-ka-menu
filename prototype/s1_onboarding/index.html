Description

This is the first screen a user sees if they have not joined a household yet. It uses a clean selection flow to guide planners and members without cluttering the mobile interface.

Google Sign-In

Users first sign in with their Google account. After authentication, they proceed to either Create New Household or Join Existing Code. The form dynamically slides in, ensuring perfect alignment.

Database Connections

Inserts a row into the households table if creating, or associates a row in members linking to the specified household code.
