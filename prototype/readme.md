# HTML/CSS Prototypes (Wireframes)

This directory contains the initial HTML and CSS wireframes for the Ghar ka Menu mobile application.

## Contents
- `index.html`: The main dashboard linking to all 8 screens.
- `styles.css`: The global design system and shared styles.
- `s1_onboarding/` to `s8_settings/`: The 8 core screens of the app, each containing their respective `index.html` and `readme.md`.

These files serve as the visual and interaction reference for the Flutter implementation.
