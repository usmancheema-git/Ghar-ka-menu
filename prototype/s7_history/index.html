Screen S7

Description

A chronological log of all past lunch records for the household. Resolves the classic family argument: "pichle hafte bhi to yehi bana tha!" — by showing an objective record.

Auto Rollover Logic

At midnight a server-side function checks yesterday's day_plans row. If status is still planned, it is automatically updated to cooked and the dish's last_cooked_on & times_cooked counters are incremented.

Data Source

Reads from day_plans table where date < today, ordered by date DESC. Both Planners and Members can view this screen.

Entry Status Legend

  • SERVED — dish was cooked and served.
  • CANCELLED — planner manually marked as skipped.
