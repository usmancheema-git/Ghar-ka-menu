Screen S3

Description

Planner-only screen. Opened by tapping the + button on an empty day in S2. Dishes are listed with recommendation sorting — longest since cooked appears at the top.

Rotation Score Logic

score = days_since_last_cooked
(never cooked = ∞ — top priority)
sort: score DESC

Repeat Warning

If a dish is already in the current 7-day rolling plan, an amber "is hafte ban chuki hai" badge appears. It's a soft warning — it does not block selection.

Category Tabs

Horizontal scrolling tabs (All, Sabzi, Daal, Chawal, Gosht, Murgh, Special) filter the list within the chosen category while keeping the same score-based sort.
