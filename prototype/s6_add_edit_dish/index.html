Add / Edit Dish

Screen S6

Description

Planner-only form for creating a new dish preset or editing an existing one. The header title dynamically reads "Add New Dish" or "Edit Preset Dish" based on entry point.

Form Fields

  • Dish Name — required, the primary identifier.
  • Category — required dropdown (Sabzi, Daal, Chawal, Gosht, Murgh, Special).
  • Ingredients — optional plain text (comma-separated). No ticking in v1.
  • Notes — optional free-text for prep tips, reminders, or family recipes.

Access Rules

Restricted to Planner role only. Supabase RLS blocks any INSERT or UPDATE from member-role tokens.

Navigation

  • S5 Add button → opens empty form
  • S5 Edit icon → opens pre-filled form
  • Save → returns to S5
