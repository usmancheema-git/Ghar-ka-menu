Description

Configuration screen for the household — join code, daily alert timing, member roster, and role display. Accessible from the bottom navigation bar by all users.

FCM Push Alerts

A Supabase Edge Function CRON job runs at the household's configured alert_time every day. It evaluates tomorrow's plan and pushes to all fcm_tokens stored in members:

  • Dish alert — sent to all members: "Kal: Chicken Biryani — ingredients check kar lo."
  • Empty day reminder — sent to Planner only: "Kal ka menu set nahi hua!"

Join Code Sharing

The 6-digit code acts as a lightweight invite. The Planner can copy it or trigger a native share intent. No email or password required for onboarding.
